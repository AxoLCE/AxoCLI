# AxoCLI
Command line tool for creating Axo mods projects
## Usage:
Open PowerShell and run this command: 
```powershell
(Invoke-WebRequest -UseBasicParsing https://raw.githubusercontent.com/AxoLCE/AxoCLI/main/axocli.py).Content | python - createproject ProjectName Package ModID
```
Replace ProjectName, Package and ModID with yours.
